🚗 Car Bidding & Auction Platform
📖 Overview

The Car Bidding & Auction Website is a modern web application that allows users to browse cars, place bids in real-time, and compete to win when the timer expires.
With its intuitive interface, bright UI theme, and real-time auction updates, it provides a seamless and engaging online auction experience.

🌟 Key Features
🧍‍♂️ User Authentication

Secure user registration and login.
🚘 Car Listings

High-quality images for each car.

💰 Real-Time Bidding System

Users can place bids during active auctions.

Countdown timer displays remaining time for each auction.

<!--Once the timer ends, the highest bidder automatically wins.-->

🕒 Auction Timer

Every car listing has a countdown timer.

Auction closes automatically when the timer reaches zero.

Bidding is locked after auction ends.

🎨 User Interface

Simple, clean, and user-friendly UI designed for smooth navigation.

Bright and modern color palette ensuring clear visibility of navigation elements.

Fully responsive layout — works seamlessly on both desktop and mobile devices.

🧭 Navigation

Minimal and visible navbar with only three main links:

Home – View active and upcoming auctions.

Auctions – Track your active and past bids.
